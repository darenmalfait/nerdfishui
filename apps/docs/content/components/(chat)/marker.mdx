## Usage


```tsx
<Marker role="status">
	<MarkerIcon>
		<Spinner />
	</MarkerIcon>
	<MarkerContent>Checking the logs...</MarkerContent>
</Marker>
```

Use `variant="separator"` for date dividers and `variant="border"` for section labels. Give status markers `role="status"` so assistive tech announces updates.
