# .agents

Agent skills and repo-specific rules for nerdfishui.

## Skills

Installed from
[`darenmalfait/nerdfish-agent-skills`](https://github.com/darenmalfait/nerdfish-agent-skills):

```bash
npx skills add darenmalfait/nerdfish-agent-skills -y
```

Lockfile: [`skills-lock.json`](../skills-lock.json) at repo root.

## Rules

[`.agents/rules/`](rules/) — only rules **not** already covered by those skills
(package boundaries, design tokens, component checklist, CI triage, …).
